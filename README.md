# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Abstract

Heart disease is one of the leading causes of death worldwide. This project focuses on building a machine learning model to predict the presence of heart disease using patient medical data.

---

## 📖 Introduction

Artificial Intelligence (AI) and Machine Learning (ML) are transforming healthcare by enabling early detection of diseases. This project demonstrates how ML can predict heart disease efficiently.

---

## 🎯 Problem Statement

To design a machine learning model that predicts whether a person has heart disease based on medical features such as:

* Age
* Blood Pressure
* Cholesterol

---

## 🎯 Objectives

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Model training
* Model evaluation
* Result interpretation

---

## ⚙️ Methodology

1. Data Collection (Kaggle/UCI dataset)
2. Data Preprocessing (cleaning + scaling)
3. EDA (graphs, heatmaps)
4. Model Training (Logistic Regression)
5. Model Evaluation (accuracy, confusion matrix)

---

## 🧹 Data Preprocessing

* Handled missing values
* Used StandardScaler for normalization

---

## 📊 Exploratory Data Analysis (EDA)

* Histograms
* Count plots
* Correlation heatmap

---

## 🤖 Model Training

* Algorithm: Logistic Regression
* Train-test split used

---

## 📈 Model Evaluation

* Accuracy Score
* Confusion Matrix
* Classification Report

---

## ✅ Results

The model achieved satisfactory accuracy and provided meaningful predictions.

---

## 🏁 Conclusion

Machine learning can effectively predict heart disease and assist in early diagnosis.
